Component Guide

다이얼로그 (Dialog / Modal System)

화면전체를 차지하는 설정 다이얼로그(`setting-dialog`), 아래에서 슬라이드 업되는 애니메이션, Focus Trap(Tab 루프 & ESC 닫기), 그리고 닫힘 시 호출 버튼으로의 포커스 자동 복원(Focus Restoration)을 지원하는 웹 접근성 표준 모달 컴포넌트입니다.

📱

화면 전체 차지 (Full Screen)

설정 화면 등 대용량 제어판에 적합하게 100dvh 모바일/데스크톱 풀스크린 모드를 지원합니다.

⬆️ 슬라이드 업 모션

아래에서 부드럽게 위로 올라오는 bottom-In 키프레임 애니메이션 트랜지션을 제공합니다.

🔁

포커스 루프 (Focus Trap)

키보드 Tab 및 Shift+Tab 탐색 시 포커스가 다이얼로그 내부를 벗어나지 않도록 제어하며 ESC 키로 닫힙니다.

🔙

포커스 복원 (Restoration)

다이얼로그를 닫을 때 열었던 최초의 버튼 요소(focus_back)로 포커스가 자동 복원됩니다.

⚙️ 설정 다이얼로그 (Full Screen & Slide-Up)

header.html 상단 설정 버튼()을 클릭하거나, 아래 테스트 버튼을 클릭하면 화면전체를 차지하는 설정 다이얼로그가 아래에서 위로 올라옵니다.

(홈 버튼, 설정 제목, 닫기 버튼, 11개 설정 및 세그먼트 스위치 토글 작동)
JavaScript & HTML Trigger 
import Dialog, { openSettingDialog, initSettingDialog } from '../component/ui-dialog.js';

// 1. 헤더 설정 버튼(.nr__allmenu-btn--setting) 클릭 이벤트 자동 연동
initSettingDialog();

// 2. 또는 자바스크립트로 직접 호출
const btn = document.querySelector('#btn-open-setting');
btn.addEventListener('click', (e) => {
  openSettingDialog(e.currentTarget);
});

💬 일반 센터 모달 & 시스템 알럿

System Dialog Code 
const sysModal = new Dialog({
  type: 'system',
  title: '설정 저장',
  message: '변경하신 설정을 저장하시겠습니까?',
  confirmText: '저장하기',
  cancelText: '취소',
  confirmCallback: () => console.log('저장 성공'),
});
sysModal.show(thisBtn);

🔼 바텀시트 다이얼로그 (Bottom Sheet)

Bottom Sheet Code 
const bottomSheet = new Dialog({
  type: 'modal',
  ps: 'bottom',
  dim: true,
  dimClick: true,
  full: false
});
bottomSheet.show(triggerButton);

📚 Dialog API & Options Reference

Option Key Type Default Description
full Boolean false 다이얼로그 화면전체(100dvh, 100%) 차지 모드 활성화
ps String 'center' 팝업 위치 ('center' | 'bottom' | 'top' | 'left' | 'right')
focus_back HTMLElement null 다이얼로그가 닫힐 때 포커스를 되돌려줄 이전 트리거 버튼 요소
dim Boolean true 배경 딤(Dimmed background) 오버레이 레이어 표시 여부
dimClick Boolean true 딤 영역 클릭 시 다이얼로그 자동 닫힘 여부
type String 'modal' 다이얼로그 종류 ('modal' | 'system' | 'toast')
title String null 시스템 다이얼로그 헤더 제목 텍스트
confirmCallback Function null 확인 버튼 클릭 시 실행할 콜백 함수

기본 센터 모달

포커스 루프(Focus Trap)와 포커스 복원(Focus Restoration) 기능이 기본 적용된 일반 중앙 다이얼로그입니다. Tab 키 및 Shift+Tab 키로 내부를 순환 탐색할 수 있습니다.
