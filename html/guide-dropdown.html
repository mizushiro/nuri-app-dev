Component Guide 2026

Dropdown & Tooltip UI Component Guide

resources/js-2026/component/ui-dropdown.js로 일원화된 올인원 드롭다운 & 툴팁 컴포넌트의 명세서 및 인터랙티브 테스트 프리뷰입니다. 스타일 클래스에 종속되지 않는 헤드리스(Headless) 속성 기반 표준([data-dropdown])을 채택하여 어디서나 충돌 없이 유연하게 확장되며, WAI-ARIA 웹접근성, 상하 자동 반전(Auto-Flip), 트리거 버튼 너비 동기화(matchWidth), 비동기 HTML 주입(loadContent), 기존 .nr__drop-* 클래스 하위 호환 및 JS API 제어를 완벽 지원합니다.

01. 기본형 드롭다운 및 방향 제어 data-position="bottom-left | bottom-right | top-left | top-right"

버튼 클릭 시 메뉴가 토글되며, 바깥 영역 클릭 또는 ESC 키 입력 시 자동으로 닫힙니다. data-position 속성으로 12가지 방향(상/하/좌/우)을 자유롭게 지정할 수 있습니다.

기본 드롭다운 (우측 정렬 & 좌측 정렬 비교)
[data-dropdown] [data-dropdown-button] [data-dropdown-panel] [data-dropdown-item]
HTML 마크업 (data-dropdown 표준) 
<!-- [data-dropdown] 기반 우측 정렬 기본 드롭다운 -->
<div class="nr__drop-wrap" data-dropdown="my-drop-menu" data-position="bottom-right">
  <button type="button" class="nr__drop-btn" data-dropdown-button="my-drop-menu" aria-controls="my-drop-menu">
    <span>기상 레이어 선택</span>
    <i class="arrow-icon" aria-hidden="true"></i>
  </button>
  <div class="nr__drop-menu" id="my-drop-menu" data-dropdown-panel="my-drop-menu">
    <ul class="nr__drop-list" data-dropdown-list role="menu">
      <li><button type="button" class="nr__item-link active" data-dropdown-item>레이더 강수 관측</button></li>
      <li><button type="button" class="nr__item-link" data-dropdown-item>낙뢰 발생 현황</button></li>
    </ul>
  </div>
</div>

<script type="module">
  import { initAllDropdowns } from '../resources/js-2026/component/ui-dropdown.js';
  // [data-dropdown] 요소 자동 감지 및 일괄 초기화
  initAllDropdowns();
</script>

02. 뷰포트 감지 상하 자동 반전 (Auto-Flip) autoFlip: true | data-auto-flip="true"

화면 하단(바닥) 근처에서 드롭다운을 열 때, 아래 공간이 메뉴 높이보다 좁으면 자동으로 위쪽(top-*)으로 방향을 뒤집어 잘림 현상을 방지합니다.

스크롤 경계 자동 반전 시연
뷰포트/스크롤 감지 상하 위치 자동 스왑

👇 아래 버튼은 data-position="bottom-right"로 설정되어 있지만, 뷰포트 하단과 닿을 때 자동으로 위쪽으로 뒤집힙니다!

✨ Auto-Flip 기능 작동 중
JavaScript 옵션 설정 
// Auto-Flip은 기본값으로 true가 활성화되어 있습니다.
initDropdown('#my-trigger', {
  autoFlip: true,     // 화면 하단 공간 부족 시 자동으로 top-* 변환
  position: 'bottom-right'
});

// 필요 시 비활성화하려면 HTML 속성 또는 옵션을 지정합니다:
// HTML: <button data-auto-flip="false" ...>
// JS: initDropdown(el, { autoFlip: false });

03. 커스텀 셀렉트박스 모드 data-match-width="true" | [data-dropdown-text]

일반 드롭다운을 커스텀 셀렉트 UI처럼 활용할 수 있습니다. 옵션을 선택하면 버튼 내 [data-dropdown-text] 텍스트가 갱신되고, 메뉴의 가로 폭이 버튼과 완벽히 일치됩니다.

너비 맞춤 셀렉트 드롭다운
matchWidth: true 라벨 동기화 onSelect 콜백
HTML & JS 
<!-- [data-dropdown] 기반 셀렉트박스 마크업 -->
<div class="nr__drop-wrap" data-dropdown="my-select" style="width: 100%; max-width: 32rem;">
  <button type="button" class="nr__drop-btn" data-dropdown-button="my-select" aria-controls="my-select" data-match-width="true" style="width: 100%;">
    <span data-dropdown-text="my-select">단기 예보 (3일간)</span>
    <i class="arrow-icon" aria-hidden="true"></i>
  </button>
  <div class="nr__drop-menu" id="my-select" data-dropdown-panel="my-select">
    <ul class="nr__drop-list" data-dropdown-list role="menu">
      <li><button type="button" class="nr__item-link active" data-dropdown-item data-value="short">단기 예보 (3일간)</button></li>
      <li><button type="button" class="nr__item-link" data-dropdown-item data-value="mid">중기 예보 (10일간)</button></li>
    </ul>
  </div>
</div>

<script type="module">
  import { initDropdown } from '../resources/js-2026/component/ui-dropdown.js';

  initDropdown('#my-select', {
    matchWidth: true,
    onSelect: (val, itemEl) => {
      console.log('선택된 예보 구분:', val);
    }
  });
</script>

04. 툴팁 및 호버(Hover) 모드 data-tooltip="true" | role="tooltip"

마우스 호버 시 자연스러운 지연 시간(hoverDelay: 150ms)을 두고 툴팁이 나타나며, 키보드 사용자에게는 Focus / Blur 이벤트로 동일하게 안내되어 완벽한 웹 접근성을 보장합니다.

접근성 지원 호버 툴팁
role="tooltip" 마우스 호버 & 키보드 포커스
체감온도 (Wind Chill) 외기에 노출된 피부가 바람과 기온의 영향으로 실제로 느끼는 온도로, 풍속 1.3m/s 이상일 때 산출됩니다.
대기질 등급 안내 좋음(0~30), 보통(31~80), 나쁨(81~150), 매우나쁨(151 이상) 4단계로 구분 고시됩니다.
HTML 마크업 (data-dropdown 표준) 
<!-- data-tooltip="true" 속성 부여 시 호버/포커스 툴팁 모드 활성화 -->
<div class="nr__drop-wrap" data-dropdown="tip-wind" data-position="top-right">
  <button type="button" class="nr__drop-btn" data-dropdown-button="tip-wind" aria-controls="tip-wind" data-tooltip="true">
    <span>체감온도 산출 기준</span>
  </button>
  <div class="nr__drop-menu" id="tip-wind" data-dropdown-panel="tip-wind" role="tooltip">
    <strong>체감온도 안내</strong>
    외기에 노출된 피부가 느끼는 온도로 풍속과 습도를 고려해 산출합니다.
  </div>
</div>

05. 기존 [data-dropdown] 마크업 호환 component.css 100% 매칭

기존 퍼블리싱 스타일인 component.css의 [data-dropdown], [data-dropdown-button], [data-dropdown-panel][data-ps] 마크업을 수정 없이 그대로 사용할 수 있도록 하위 호환 매핑을 완벽 지원합니다.

[data-dropdown] 클래스 없는 속성 기반 제어
[data-dropdown="id"] [data-dropdown-button] [data-dropdown-panel]
레거시 마크업 호환 문법 
<!-- 기존 component.css 방식의 [data-dropdown] 구조도 동일하게 자동 초기화됩니다 -->
<div data-dropdown="my-layer">
  <button type="button" data-dropdown-button="my-layer">
    <span data-dropdown-text="my-layer">레이어 선택</span>
  </button>
  <div data-dropdown-panel="my-layer" data-ps="bl">
    <div data-dropdown-section="my-layer">
      <ul data-dropdown-list role="menu">
        <li><button type="button" class="nr__item-link" data-dropdown-item>전국 기상 위성</button></li>
      </ul>
    </div>
  </div>
</div>

06. 비동기 템플릿 로딩 (loadContent / src) data-src="./inc/..." | loadContent

초기 HTML에 레이어 내용을 포함하지 않고, 필요할 때 외부 HTML 파일(./inc/*.html)을 비동기(AJAX)로 패널에 주입하여 첫 화면 로딩 속도를 최적화합니다.

외부 HTML 파일 비동기 삽입 데모
data-src 동적 바인딩 자동 갱신
HTML & JS 
<!-- [data-dropdown] 기반 비동기 템플릿 로딩 -->
<div class="nr__drop-wrap" data-dropdown="my-async-menu" data-position="bottom-right">
  <button type="button" class="nr__drop-btn" data-dropdown-button="my-async-menu" aria-controls="my-async-menu" data-src="./inc/dropdown-async-sample.html">
    <span>비동기 데이터 패널</span>
  </button>
  <div class="nr__drop-menu" id="my-async-menu" data-dropdown-panel="my-async-menu"></div>
</div>

<script type="module">
  import { initDropdown } from '../resources/js-2026/component/ui-dropdown.js';

  initDropdown('#my-async-menu', {
    src: './inc/dropdown-async-sample.html',
    srcCallback: () => {
      console.log('외부 템플릿 로드 완료!');
    }
  });
</script>

07. 메인 방재속보 / 전국특보 토글 패널 initNoticeDropdown | 당일 자정 쿠키 만료

상단 방재속보 및 전국특보 버튼을 상호 배타적으로 열고 닫으며, '오늘 하루 열지 않기' 체크박스 선택 시 당일 23:59:59까지 유효한 쿠키와 로컬스토리지를 설정하여 팝업 노출을 제어합니다.

방재속보 / 전국특보 제어 시스템
쿠키 만료: 당일 자정 window.noticeDropdown

* 메인 화면(main.html) 상단 헤더에 탑재되어 있으며 전역 객체 window.noticeDropdown으로 어디서든 제어 가능합니다.

JavaScript API 
import { initNoticeDropdown } from '../resources/js-2026/component/ui-dropdown.js';

const notice = initNoticeDropdown({
  defaultOpen: 0 // 최초 방문 시 0번(방재속보) 기본 열림 (오늘 안보기 쿠키 유효 시 자동 닫힘)
});

// 전역 호출 지원
window.openNotice('disaster'); // 0번 방재속보 열기
window.openNotice('special');  // 1번 전국특보 열기
window.closeNotice();         // 패널 닫기

데이터 속성 규격 ([data-dropdown*] Attributes)

클래스명 의존도를 제거하고 동작과 상태를 선언적으로 연결하는 표준 데이터 속성입니다.

데이터 속성 대상 요소 필수 여부 설명
data-dropdown="[id]" 컨테이너 (Wrapper) 선택 드롭다운 컴포넌트의 유효 범위(Scope)를 정의하며 고유 ID를 부여합니다.
data-dropdown-button="[id]" 트리거 버튼 권장 드롭다운을 열고 닫는 토글 버튼입니다. aria-controls와 동일하게 패널 ID와 매핑됩니다.
data-dropdown-panel="[id]" 메뉴/패널 레이어 권장 드롭다운 팝업 콘텐츠 레이어입니다.
data-dropdown-item 항목 버튼/링크 권장 드롭다운 내부 선택 가능한 아이템에 부여하며, 활성화 시 data-selected="true"가 자동 동기화됩니다.
data-dropdown-close 내부 닫기 버튼 선택 패널 내부에 위치하는 닫기 버튼에 부여 시 클릭 이벤트가 자동으로 바인딩됩니다.
data-dropdown-text="[id]" 라벨 텍스트 요소 선택 선택된 아이템의 텍스트로 자동 갱신되는 라벨 요소입니다.
data-state="open | closed" 버튼 / 패널 / 래퍼 자동 부여 현재 열림/닫힘 상태를 엔진에서 실시간 업데이트하며, CSS 선택자로 직관적 스타일링이 가능합니다.
data-position="bottom-right | ..." 래퍼 또는 패널 선택 12가지 방향(bl, bc, br, tl, tc, tr, lt, lc, lb, rt, rc, rb) 위치를 설정합니다.
data-match-width="true" 버튼 또는 패널 선택 버튼 너비와 메뉴 패널 너비를 1:1로 일치시킵니다. (셀렉트박스 모드)
data-auto-flip="true | false" 버튼 또는 패널 선택 화면 상/하 경계 도달 시 자동 반전 활성화 여부를 제어합니다 (기본값: true).
data-src="./path.html" 버튼 또는 패널 선택 비동기로 주입할 외부 HTML 파일 조각의 경로를 지정합니다.

옵션 (Options) 명세서

옵션명 타입 기본값 설명
position String 'bottom-right' 드롭다운 열림 방향 (bottom-left, bottom-right, top-left, top-right 등)
ps String null component.css 단축 위치 약어 (bl, br, tl, tr, rt, lt 등). position과 자동 동기화
autoFlip Boolean true 뷰포트 하단/상단 공간 부족 시 반대 방향으로 자동 반전 여부
matchWidth Boolean false 트리거 버튼과 드롭다운 레이어의 가로 폭(width)을 1:1로 일치시킬지 여부
isTooltip Boolean false 호버(Hover) 및 포커스(Focus) 툴팁 모드 활성화
hoverDelay Number 150 툴팁 모드 마우스 진입/이탈 지연 시간(ms)
src String null 비동기로 패널에 주입할 외부 HTML 파일 경로 (loadContent 연동)
onSelect Function null 아이템 클릭 선택 시 호출되는 콜백 (value, itemElement)
onOpen / onClose Function null 패널이 열리거나 닫힐 때 호출되는 이벤트 콜백 (instance)

인스턴스 메서드 (Instance Methods)

메서드 파라미터 설명
open(shouldFocus = true) shouldFocus: boolean 드롭다운을 열고 첫 번째 아이템으로 포커스를 이동합니다.
close(restoreFocus = true) restoreFocus: boolean 드롭다운을 닫고 원래 열었던 트리거 버튼으로 포커스를 복원합니다.
toggle() - 현재 상태를 반전하여 열거나 닫습니다.
setPosition(positionString) pos: string 드롭다운 위치 및 data-ps를 동적으로 변경합니다.
destroy() - 등록된 모든 이벤트 리스너(클릭, 키보드, 윈도우 스크롤/리사이즈) 및 인스턴스를 해제합니다.
selectItem(itemElement) item: HTMLElement 특정 아이템을 프로그래밍 방식으로 선택 상태로 설정하고 닫습니다.
isOpen() - 현재 열려있는지 여부(Boolean)를 반환합니다.
코드가 클립보드에 복사되었습니다.
