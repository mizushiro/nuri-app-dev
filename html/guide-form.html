Form Controls & Fake Button Guide

resources/css-2026/ui.common.css에 선언된 폼 컨트롤 컴포넌트(페이크 폼 버튼, 라인 리스트, 스위치 토글, 인디케이터 배지, 드롭다운 셀렉트)의 명세서 및 인터랙티브 프리뷰입니다.

라인 리스트형 (line-list-type) 라인 리스트형2 (line-list-type2) 텍스트 선택형 (text-type) 라운드 박스 탭 (round-box) 드롭다운 / 셀렉트 버튼 리스트형 칩 / 태그 (round-list-type) 스위치 토글 (form-element-switch) 인디케이터 마커 (.in-square, .in-round) 기본 체크박스 (.form-element-check)

모바일 스위치 토글 .form-element-switch

설정 및 알림 켜기/끄기에 사용되는 네이티브 스위치 컴포넌트입니다. 부드러운 0.3s 트랜지션, .txt-uncheck와 .txt-checked 텍스트 전환, data-size="20" 및 disabled 상태를 지원합니다.

스위치 토글 데모
.form-element-switch [data-size="20"]
1. 미니 사이즈 스위치 (data-size="20")
알림 수신 (기본 켜짐)
2. 꺼진 상태 (Unchecked)
야간 방해금지 (꺼짐)
3. 비활성 상태 (Disabled)
설정 불가 항목
HTML 
<!-- 스위치 토글 (ON / OFF 텍스트 내장) -->
<div class="form-element-switch" data-size="20">
  <input type="checkbox" id="switchAlert" checked>
  <label for="switchAlert">
    <span class="txt-checked">ON</span>
    <span class="txt-uncheck">OFF</span>
  </label>
</div>

상태 인디케이터 배지 .in-square-area | .in-round-area

지도 범례나 레이어 목록, 표의 범례에 사용되는 규격(1.4rem x 1.4rem) 컬러 박스 인디케이터입니다.

사각형 & 원형 인디케이터
블루 스퀘어 영역 (.in-square-area) - 보더 #2978ED
그린 라운드 영역 (.in-round-area) - 보더 #3CC74A
HTML 
<!-- 사각형 인디케이터 -->
<span class="in-square-area" aria-hidden="true"></span>

<!-- 원형 인디케이터 -->
<span class="in-round-area" aria-hidden="true"></span>

기본 체크박스 & 라디오 .form-element-check

네이티브 인풋(.native-input)을 숨기고 SVG 배경 이미지(icon-aspect-check-off / on)를 적용한 표준 체크 컨트롤입니다.

체크박스 컨트롤
HTML 
<div class="form-element-check">
  <input type="checkbox" class="native-input" id="agree1" checked>
  <label for="agree1" class="label-value">이용약관 동의</label>
</div>

폼 속성 (Data Attributes) 레퍼런스

주요 속성과 클래스 조합 명세입니다.

속성 / 클래스 지원 값 설명
data-form-style line-list-type, line-list-type2, round-box, round-list-type, square-list-type, text-type, text-color-type 폼 버튼 그룹의 비주얼 스타일 유형 결정
data-col 1, 2, 3, 4, auto 그리드 열 수 분할 (data-col="auto"는 컨텐츠 너비에 맞춤)
data-form-h 28, 32, 34, 40, 42, 44, 46, 48 버튼의 고정 높이 (단위: rem, 예: 44 = 4.4rem = 44px)
data-item-size 42, 46, 58, 80, 88, 96, 104 아이템 라벨의 최소 너비 (min-width)
.form-fake-input type="radio" | type="checkbox" 투명하게 숨겨진 네이티브 인풋 (접근성 및 키보드 조작 지원)
.form-element-switch data-size="20" 모바일 슬라이드형 스위치 토글 컨테이너
.in-square-area / .in-round-area 단일 클래스 지도나 표 범례에 사용하는 미니 인디케이터 배지
코드가 클립보드에 복사되었습니다!
