Accordion UI Component Guide

resources/js-2026/component/ui-accordion.js 기반의 올인원 아코디언 컴포넌트 명세서 및 인터랙티브 테스트 가이드입니다.
ui-dropdown.js와 동일하게 자동 실행 함수(initAllAccordions)와 개별 실행 함수(initAccordion)를 일원화 지원하며, WAI-ARIA 웹접근성, 단일/다중 열림 제어(singleOpen), 키보드 방향키 탐색, URL 파라미터 자동 확장 및 라이프사이클 관리(destroy, update)를 제공합니다.

01. 단일 열림 모드 (Single Open Mode) singleOpen: true (기본값)

한 번에 오직 하나의 아코디언 항목만 열릴 수 있습니다. 다른 항목을 클릭하면 기존에 열려있던 항목이 부드럽게 닫힙니다.

기본 단일 열림 아코디언
[data-accordion] [data-accordion-item] [data-accordion-button] [data-accordion-body]
호우 경보 발령 시 하천변, 지하차도, 산사태 위험 지역의 출입을 금지하고 최신 기상 특보 방송을 청취하며 안전한 고지대로 대피하십시오.
자가용 운행을 자제하고 지하철 및 시내버스 등 대중교통을 이용해 주시기 바라며, 내 집 앞 눈 치우기에 적극 동참해 주세요.
해안가 갯바위 및 방파제 낚시객은 즉시 철수해야 하며, 항포구 선박은 결박 상태를 점검하여 풍랑 피해를 예방하십시오.
HTML 마크업 (data-accordion 표준) 
<!-- [data-accordion] 단일 열림 기본 아코디언 마크업 -->
<div class="nr__accordion-wrap" data-accordion="acco-faq">
  <div class="nr__accordion-item" data-accordion-item="acco-faq">
    <button type="button" class="nr__accordion-btn" data-accordion-button="acco-faq">
      <span data-accordion-title="acco-faq">질문 제목 1</span>
      <span class="arrow-icon" aria-hidden="true">▼</span>
    </button>
    <div class="nr__accordion-body" data-accordion-body="acco-faq">
      답변 내용 1
    </div>
  </div>
</div>

<script type="module">
  import { initAllAccordions } from '../resources/js-2026/component/ui-accordion.js';
  // 페이지 내 모든 아코디언 자동 초기화
  initAllAccordions();
</script>

02. 다중 열림 모드 (Multi Open Mode) data-single-open="false" | singleOpen: false

data-single-open="false" 속성을 지정하면 여러 항목을 동시에 열거나 펼쳐둔 상태로 유지할 수 있습니다.

다중 열림 지원 아코디언
data-single-open="false" 독립 토글
레이더 강수 관측 및 합성 영상 데이터의 업데이트 주기는 5분 단위입니다.
천리안 2A호 위성의 적외선, 가시광선, 수증기 영상을 실시간으로 수집합니다.
HTML & JS 
<!-- data-single-open="false" 속성으로 다중 열림 지정 -->
<div class="nr__accordion-wrap" data-accordion="my-multi" data-single-open="false">
  ...
</div>

<script type="module">
  import { initAccordion } from '../resources/js-2026/component/ui-accordion.js';

  // JS 옵션으로 다중 열림 설정 시:
  initAccordion('#my-multi', {
    singleOpen: false
  });
</script>

03. 초기 열림 및 URL 파라미터 연동 data-expanded="0" | ?acco=btn_id

data-expanded="0" 속성이나 JS 옵션(expanded: 0)으로 특정 인덱스/ID 항목을 초기 오픈 상태로 지정할 수 있으며, URL Query String에 ?acco=버튼ID가 포함되면 해당 항목이 자동으로 확장됩니다.

첫 번째 항목(0번) 기본 열림 시연
data-expanded="0" ?acco=... URL 파라미터 지원
이 항목은 data-expanded="0" 설정에 의해 로딩 시 자동으로 열려 있는 상태로 렌더링됩니다.
두 번째 항목입니다.
HTML & JS 
<!-- data-expanded="0" 으로 0번째 인덱스 자동 열림 -->
<div class="nr__accordion-wrap" data-accordion="my-default" data-expanded="0">
  ...
</div>

<!-- URL 직접 접근 링크 예시 -->
<a href="guide-accordion.html?acco=my-default-btn-1">특정 아코디언 다이렉트 링크</a>

04. 클래스 기반 마크업 하위 호환 .nr__accordion-wrap | .accordion-wrap

기존 프로젝트 코드베이스의 .nr__accordion-wrap, .accordion-wrap, .accordion-item, .accordion-btn 클래스 마크업을 변경 없이 그대로 동작하도록 하위 호환을 보장합니다.

클래스 기반 기존 마크업 호환 시연
.nr__accordion-wrap .nr__accordion-item .nr__accordion-btn
클래스 요소 탐색을 통해 data-* 속성이 없어도 자동 감지되어 ARIA 속성과 이벤트를 할당합니다.
두 번째 기존 클래스 아코디언 내용입니다.
HTML 마크업 
<!-- 기존 클래스 방식 마크업도 initAllAccordions()로 자동 초기화됩니다 -->
<div class="nr__accordion-wrap">
  <div class="nr__accordion-item">
    <button type="button" class="nr__accordion-btn">
      <span>타이틀 1</span>
      <span class="arrow-icon">▼</span>
    </button>
    <div class="nr__accordion-body">내용 1</div>
  </div>
</div>

05. WAI-ARIA 웹접근성 & 키보드 내비게이션 ArrowNavigator | Keydown Focus Loop

모든 아코디언 항목은 aria-expanded, aria-controls, role="region", aria-labelledby 속성이 자동 할당됩니다.
아코디언 버튼에 포커스 후 키보드 방향키(↑, ↓), Home, End 키로 자유롭게 다른 버튼으로 포커스를 이동할 수 있습니다.

키보드 방향키 포커스 이동 시연 (버튼 클릭 후 ↑ / ↓ 테스트)
ArrowUp / ArrowDown Home / End 키 aria-expanded
Focus가 형성된 상태에서 키보드 탐색이 원활하게 동작합니다.
Home 키 누를 시 첫 번째, End 키 누를 시 마지막 항목으로 이동합니다.
WAI-ARIA 1.2 아코디언 디자인 패턴을 엄격히 준수합니다.

06. JavaScript API 제어 & 인터랙티브 플레이그라운드 show / hide / openAll / closeAll / destroy

JS 반환 인스턴스 메서드를 이용하여 외부 코드로 특정 항목을 열거나 닫을 수 있으며, 콜백 함수(onOpen, onClose, onToggle) 이벤트를 콘솔 창에서 확인할 수 있습니다.

인터랙티브 API 컨트롤 패널
.show(target) .hide(target) .openAll() .closeAll() .destroy()
플레이그라운드 0번 내용입니다.
플레이그라운드 1번 내용입니다.
플레이그라운드 2번 내용입니다.
[시스템] 아코디언 API 플레이그라운드가 준비되었습니다. 버튼을 클릭해보세요.

07. API 명세서 및 데이터 속성 규격 Developer Reference

아코디언 컴포넌트 개발 시 사용할 수 있는 내보내기 함수, 인스턴스 메서드, 전달 옵션 및 마크업 데이터 속성 테이블입니다.

1. 모듈 내보내기 함수 (Export Functions)

함수명 매개변수 반환값 설명
initAllAccordions(root) root=document Array<Instance> 페이지 내 모든 아코디언 컨테이너를 자동 탐색하여 초기화합니다.
initAccordion(target, options) (Selector|Element|Object, Object) Instance|null 단일 아코디언 요소를 지정하여 옵션과 함께 초기화하고 제어 인스턴스를 반환합니다.
new Accordion(options) Object Accordion Class 기존 Dropdown / Accordion 클래스 어댑터 구조로 객체 생성 후 .init() 호출이 가능합니다.

2. 인스턴스 메서드 (Instance Methods)

메서드명 인자값 설명
instance.show(target, callback) target: Index(Number) | ID(String) | Button(Element) 지정한 아코디언 항목을 슬라이드 다운 애니메이션과 함께 엽니다.
instance.hide(target, callback) target: Index(Number) | ID(String) | Button(Element) 지정한 아코디언 항목을 슬라이드 업 애니메이션으로 닫습니다.
instance.toggle(target, callback) target: Index(Number) | ID(String) | Button(Element) 열려있으면 닫고, 닫혀있으면 엽니다.
instance.openAll() 없음 아코디언 내 모든 항목을 엽니다.
instance.closeAll() 없음 아코디언 내 모든 항목을 닫습니다.
instance.update() 없음 동적으로 HTML 항목이 추가/삭제된 후 최신 DOM 상태로 재초기화합니다.
instance.destroy() 없음 등록된 모든 이벤트 리스너와 키보드 내비게이션 및 메모리를 해제합니다.
instance.isOpen(target) target: Index | ID | Element 해당 항목이 열려 있는지 여부(Boolean)를 반환합니다.

3. 데이터 속성 규격 ([data-accordion*] Attributes)

데이터 속성 적용 대상 설명
data-accordion="[id]" 컨테이너 요소 아코디언 컴포넌트 범위를 지정하며 고유 식별자 ID를 등록합니다.
data-single-open="true|false" 컨테이너 요소 단일 열림(true) 또는 다중 열림(false) 모드를 지정합니다.
data-expanded="[index|id]" 컨테이너 요소 페이지 로드 시 초기 오픈 상태로 열어둘 항목을 지정합니다.
data-accordion-item="[id]" 아이템 감싸는 요소 아코디언의 개별 아이템 블록을 지정합니다.
data-accordion-button="[id]" 트리거 버튼 아코디언 열기/닫기 클릭 및 포커스 대상 버튼입니다.
data-accordion-title="[id]" 타이틀 텍스트 버튼 접근성 라벨(aria-label) 설정 시 참조되는 텍스트 영역입니다.
data-accordion-body="[id]" 콘텐츠 패널 슬라이드 토글 대상이 되는 본문 영역입니다.
코드가 클립보드에 복사되었습니다.
