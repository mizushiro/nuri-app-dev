누리앱 아이콘 시스템 규격 및 개발 사용 가이드

1. Aspect-Ratio 아이콘 (icon-aspect-*)

aspect-ratio: 1/1과 background-size: contain을 기반으로 작동하며, data-size 속성을 통해 원하는 크기로 즉시 렌더링됩니다.

<i class="icon-aspect-location-w" data-size="24" aria-hidden="true"></i>
data-size 6101418222630364880
rem 환산 .6rem1rem1.4rem1.8rem2.2rem2.6rem3rem3.6rem4.8rem8rem

* data-opacity="0.3", "0.6", "0.8" 투명도 속성도 즉시 적용 가능합니다.

2. CSS Mask 아이콘 (icon-mask-*)

mask-image와 background-color: currentColor를 활용하여 부모 텍스트 색상 또는 CSS color 속성을 그대로 상속받습니다.

<!-- 텍스트 색상 또는 style="color: ..." 로 즉시 색상 제어 --> <i class="icon-mask-my" style="color: #0475F4;" aria-hidden="true"></i>

• icon-mask-my (3.4rem / 기본 var(--text-theme1))
• icon-mask-setting, close, arrow, style* (2.4rem)
• icon-mask-menu1~10 (1.8rem / 기본 var(--text-theme6))

3. 기상청 날씨 (NB01~NB21) 및 음력 달의 위상

기상청 표준 예보 코드(NB01 맑음부터 NB21 박무까지 21종) 및 음력 8단계 달의 위상(img-moon-01 월삭부터 08 그믐달까지)이 고화질 PNG 렌더링으로 지원됩니다.

<!-- 날씨 비 아이콘 32px --> <i class="icon-aspect-NB04" data-size="32" aria-hidden="true"></i> <!-- 보름달 아이콘 28px --> <i class="icon-aspect-moon5" data-size="28" aria-hidden="true"></i>

4. 웹 접근성 (A11y) 표준 가이드

아이콘은 스크린 리더에서 불필요한 음성 낭비를 방지하기 위해 aria-hidden="true"를 반드시 선언해야 합니다.

<!-- 텍스트가 없는 단독 아이콘 버튼에는 상위 버튼에 aria-label 지정 --> <button type="button" aria-label="메뉴 닫기"> <i class="icon-aspect-close" aria-hidden="true"></i> </button>
